Before you ship it

1 · Host the logo

Email clients can't use SVG, so export two PNGs (transparent background, at 2× size for sharpness) and upload them somewhere public:

  • gostops-icon.png — the monogram, 116×116px (used by signatures 1 & 3)
  • gostops-logo.png — the wordmark, ~56px tall (used by signature 2)

Then in the copied HTML, replace the placeholder https://www.gostops.com/email/... paths with your real image URLs. Until you do, the preview above uses an embedded copy so you can see the design.

2 · Edit the details

Click Show HTML, then swap the name, title, phone, and email. Keep phone numbers in two places consistent: the visible text and the tel: link. Signature 3's button points at the person's digital contact card — update /vc/prateek.

3 · Install in Gmail

  1. Click Copy signature above.
  2. Gmail → Settings (gear) → See all settings → General → Signature.
  3. Create a signature, click into the box, and paste (Cmd/Ctrl + V).
  4. Save changes at the bottom.

4 · Install in Outlook

  1. Click Copy signature above.
  2. Outlook → Settings → Mail → Compose and reply → Email signature.
  3. Paste into the box and save. (Desktop Outlook: New Email → Signature → Signatures → paste.)

Every signature is pure HTML tables with inline styles — no scripts, no web fonts — so it renders consistently across Gmail, Outlook, and Apple Mail. The finger stripe is drawn from coloured table cells, so it shows even when a reader blocks images.
